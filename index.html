Роблокс Підтримка+1

Зато можно сделать нормальную кнопку «ВХОД» без хранения паролей:

ВХОД →
NickName ROBLOX: [________]
[ 🔐 ВОЙТИ ЧЕРЕЗ ROBLOX ]

Пользователь переходит на официальную авторизацию Roblox, а твоё приложение получает подтверждённую личность через Roblox OAuth/OpenID Connect. Roblox сейчас предоставляет OAuth 2.0 с PKCE и openid/profile для такой авторизации. Creator Hub+1

После успешного входа мы можем сохранять у тебя безопасно:

Roblox username
Roblox user ID
Ссылка на профиль
Дата входа
История апгрейдов

А для ручной помощи игрокам можем сделать админский журнал, например:

[06.10.2026 23:58]
Игрок: Vlad123
Roblox ID: 123456789
Действие: запрос помощи
Комментарий: "Не пришёл питомец"

Так ты получишь нужную тебе информацию для поддержки, но пароли игроков вообще не будут попадать ни тебе, ни в текстовые файлы.
